# DecodeLabs Project 2: Exploratory Data Analysis (EDA) Using Excel

## Project Overview
This project involved exploring and analysing an order dataset containing 1,200 records covering 2023 to 2025. Microsoft Excel was used to identify patterns in product distribution, monthly order activity, price distribution, and potential outliers.

## Tools Used
- Microsoft Excel
- PivotTables and PivotCharts
- Descriptive statistics
- Interquartile Range (IQR) method for outlier detection

## Analysis Performed
- Analysed the distribution of orders across products.
- Examined monthly order trends from 2023 to 2025.
- Created a histogram to examine the distribution of total prices.
- Calculated descriptive statistics, including the mean and median.
- Used the IQR method to identify potential outliers in quantity, unit price, and total price.
- Prepared an EDA summary sheet highlighting the key findings.

## Key Findings
- Printer had the highest number of orders, with 181 records, followed by Tablet (179) and Chair (178).
- June 2024 recorded the highest monthly order count, with 53 orders.
- No outliers were identified in quantity or unit price using the IQR method.
- Eight potential outliers were identified in total price.
- The total price distribution was right-skewed, indicating that some orders had considerably higher total prices than others.
